# 清凉校园 · 热浪行动 —— 微信小程序（原生版）

这是一个**可在微信开发者工具里直接导入运行、不需要任何域名与服务器**的原生小程序：
地图由 Canvas 2D 绘制，规则引擎与 H5 版完全同源（同一份 TypeScript 编译而来），横屏展示。

> 为什么不用 web-view 套壳：个人主体小程序不支持 web-view（后台没有业务域名入口），
> 企业主体又要求 ICP 备案的 HTTPS 域名。原生版不需要域名、不需要备案、不需要提审——
> 开发版扫「预览」码自己手机就能玩；要给评委玩，上传一个「体验版」并把他们加为体验成员即可。

## 一、目录结构

```
wechat-miniprogram/
├── project.config.json     项目配置（已填项目 AppID）
├── app.json / app.js / app.wxss
├── sitemap.json
├── core/                   ★ 编译产物（勿手改）：引擎 + 关卡数据，来自主项目
│   ├── lib/engine.js          规则引擎（放置/推进/结算/自动布置…）
│   ├── lib/iso.js             等距投影与配色数学
│   ├── lib/feedback.js        操作反馈文案
│   └── data/*.js              地图、群体、工具、关卡数据
├── render/                 ★ Canvas 渲染层（由主项目 IsoMap/MapArt 移植）
│   ├── geometry.js            等轴几何（地块/立面/檐口/屋顶点）
│   ├── hit.js                 取景换算 + 点击命中测试
│   └── draw.js                整张地图的 Canvas 绘制管线
└── pages/game/             游戏页：WXML 三栏界面 + 工具坞 + 弹窗
```

**重新编译 core/**（改动主项目引擎后执行一次，然后把本文件夹导入工具）：

```bash
cd <主项目根目录>
npm run mp:build        # = tsc -p tsconfig.mp.json
```

## 二、运行（开发版，自己看）

1. 下载安装「微信开发者工具」（稳定版），微信扫码登录；
2. **导入项目**：目录选本文件夹（`wechat-miniprogram/`），AppID 会自动读 `project.config.json` 里已填好的项目 AppID；
3. 点「编译」——模拟器里直接出现横屏游戏（页面已配置 `pageOrientation: landscape`）；
4. 点 **「预览」**，手机微信扫码 → 手机上直接玩开发版（免费、不限次数；改一次扫一次）。

> 首次打开模拟器若提示“游客模式”，在「详情 → 基本信息」里确认 AppID 是你的项目 AppID。
> 本工程不依赖 npm 包、不联网、不需要「不校验合法域名」。
>
> **AppID 说明（重要）**：本项目是标准小程序（WXML/CSS），必须用**「小程序」类型**的 AppID；**「小游戏」账号无法编译本项目**
> （小游戏只能跑 game.js/game.json，会报“未找到 game.json”）。若工具打开项目时顶部显示“小游戏模式”，说明当前 appid 是小游戏账号，
> 需换成正式「小程序」AppID 才能上传体验版；本地开发可临时用测试号（测试号不能上传）。
> 注：公众平台后台“AppID(小程序ID)”这行字两种类型都这么写，不能用于判断类型；以工具顶部模式和服务类目为准。

## 三、发给别人玩（体验版，不公开）

1. 工具右上角点 **「上传」**（版本号随意，如 1.0.0）；
2. 打开 [微信公众平台](https://mp.weixin.qq.com) → 「管理 → 版本管理」→ 把刚上传的版本设为 **「体验版」**（无需审核）；
3. 「管理 → 成员管理 → 体验成员」添加对方的微信号（**个人主体上限 15 人**，给评委够用）；
4. 把体验版二维码发给他们，扫码即玩。**全程不提审、不发布、不对外公开。**

## 四、玩法对应

- **选工具 → 点地块放置**：放置前手指按住地块会显示「效果预览卡」（提前看到各指标变化）；
- 放置后左上角弹出**操作反馈卡**（用大白话解释这一步好在哪里）；
- 左下角滑条拖动可**任意角度旋转地图**，`↺ / ↻` 微调，`⌂` 复位；
- 左栏：当前态势、图层开关（热力/遮阴/人群/脆弱群体）、**撤销**（任何一步都能一键回退）、**✦ 自动布置方案**（一键达标）；
- 右栏：任务目标（实时进度）、地块详情（点击地块查看）、决策记录；
- 点击**图书馆/阅览馆**可设置纳凉开放时段；推进时间途中会触发现场事件（有的需要做选择）。
