# 《清凉校园 · 热浪行动》玩法与规则说明

> 本文档用于答辩讲解与规则核对。所有数值均为**为本作品设定的原型模拟参数**，
> 不是实测温度、工程预算或经认证的降温效果，也不能用于真实区域评估。

---

## 一、背景与目标

你是校园里的**学生规划志愿者**。热浪持续，校园里的温度并不均等：
中心广场的地砖、田径场的塑胶跑道、后勤保洁的水泥院子、外卖集散点最热，
而教学楼里、水岸边最凉。

你需要在有限的**预算**和**施工档期**里，为地块选择降温改造，
让尽可能多的人离开“高暴露”，并且——这一点最重要——
**让脆弱群体的改善幅度不低于平均。**

### 三类目标（对应“护人 / 护空间 / 护公平”）

1. **护人**：降低户外高暴露人数，尤其是脆弱群体；
2. **护空间**：把遮阴、蒸散、舒适度放在真正有人、真正热的地方，而不是只看地图好不好看；
3. **护公平**：公平差达标——脆弱群体的高暴露率不能高于学生太多。

> 关于“伤亡指标”：本作品不显示伤亡数字。热浪的健康后果是严肃议题，
> 作品用“高暴露人数 / 脆弱群体高暴露率 / 公平差 / 舒适度”来表达风险，
> 并明确这是决策推演，不是灾情预测。

## 二、时间与回合

| 时刻 | 热力系数 | 人群特征 |
| --- | --- | --- |
| 08:00 上午 | 0.82 | 学生在教学楼，儿童在幼儿园户外活动 |
| 12:00 正午 | 1.06 | 食堂与道路人流高峰，广场开始暴晒 |
| 14:00 午后 | 1.12 | 一天最热，广场、田径场、后勤院子全部高暴露 |
| 18:00 傍晚 | 0.88 | 人流转向田径运动场与公寓，塑胶跑道仍在放热 |

- 没有回合行动点、没有冷却：改造**随时都能放**，唯一限制是**预算**。
- 点“推进时间”只是把时刻推向下一段（人群与热力会变），不是“本回合结束”。
- 改造一旦建成是**永久**的，可以随时拆除并退回预算。
- 走完最后一个时刻进入**结算复盘**。

### 视角

地图支持**任意角度旋转**：拖右下角的滑块可连续转动，拖到多少度就转多少度（或按 `Q` / `E` 每次微调 15°，⌂ 复位）。
转动的是一整个**三维微缩模型**——地面在任何角度都是正确的斜投影（地块投影成平行四边形），
建筑的可见立面按外法线连续剔除，光照固定在世界方向（不随视角跳变）。
旋转后遮挡关系会重新计算，因此被高楼挡住的地块换一个角度即可点击——这也是“有些设置要到另一个角度才能完成”的解决办法。

## 三、地表热指数模型

```
tile.heat = clamp(
    baseHeat(tile) × hourMult(hour) × weatherMult(weather) + heatDelta
    − shade(tile) − evap(tile),
  12, 100 )
```

- `baseHeat`：地块基础热度（原型值），由下垫面类型决定，个别地标有覆盖值。
- `hourMult`：上表的时刻系数。
- `weatherMult`：常规晴热 1.0 / 黄色预警 1.06 / 橙色预警 1.12 / 雷阵雨转晴 0.9。
- `heatDelta`：事件带来的全局修正（例如“午后热浪继续”+4、“预警升级”+5）。
- `shade`：所有遮阴类工具的距离衰减叠加，**单点上限 40**。
- `evap`：所有蒸散 / 反射类工具的距离衰减叠加，**单点上限 32**。

**距离衰减**（`falloff`）：

```
w(d, R) = max(0, 1 − (d / R)^1.6)
```

即中心处效果为 1，边缘处为 0，中间偏“饱满”，符合成片遮阴的直觉。

## 四、人群模型与“户外暴露”口径

每个地块有一个**档案**（profile），决定：

- `mult[4]`：四个时刻的人数比例（峰值缩放）；
- `outdoor[4]`：四个时刻的**户外暴露比例**；
- `mix`：五类人群的构成比例。

```
地块人数       = 峰值人数 × mult[时刻]
户外暴露人数   = 地块人数 × outdoor[时刻]
```

| 档案 | 08:00 | 12:00 | 14:00 | 18:00 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 教学科研 | 1.00 | 0.35 | 0.50 | 0.50 | 室外比例 0.30 / 0.12 / 0.15 / 0.30 |
| 公共活动（广场） | 0.50 | 1.00 | 0.70 | 0.90 | 室外比例 0.90 / 1.00 / 0.95 / 1.00 |
| 生活起居（公寓） | 0.45 | 0.35 | 0.50 | 0.90 | 室外比例 0.20 / 0.15 / 0.20 / 0.40 |
| 就餐 | 0.55 | 1.00 | 0.35 | 1.00 | 室外比例 0.40 / 0.75 / 0.30 / 0.75 |
| 运动 | 0.50 | 0.25 | 0.35 | 1.00 | 室外比例 0.90 / 0.50 / 0.60 / 1.00 |
| 医疗 | 0.70 | 0.80 | 0.80 | 0.50 | 室外比例 0.40 |
| 幼教 | 1.00 | 0.60 | 0.70 | 0.05 | 室外比例 0.65 / 0.45 / 0.45 / 0.10 |
| 通勤 / 配送 | 0.60 | 1.00 | 0.80 | 0.70 | 室外比例 0.90 / 1.00 / 1.00 / 0.90 |
| 绿地游憩 | 0.15 | 0.20 | 0.20 | 0.30 | 室外比例 0.90 |
| 道路通勤 | 0.90 | 0.50 | 0.50 | 0.70 | 室外比例 1.00 / 0.90 / 0.90 / 1.00 |
| 后勤服务 | 0.80 | 0.90 | 0.90 | 0.40 | 室外比例 **1.00** |

> 为什么用“户外暴露”：屋顶再烫，也不等于站在教室里的人被暴晒。
> 把户外比例独立出来，才能体现“保洁、门岗、绿化、骑手几乎全天在户外”这一被忽视的事实。

## 五、人群与脆弱度权重

| 人群 | 权重 | 说明 |
| --- | --- | --- |
| 学生 | 1.0 | 数量最多，室内外切换多，风险相对分散 |
| 儿童 | 1.8 | 体温调节能力弱，幼儿园与家属区是重点 |
| 老人 | 1.9 | 心脑血管风险高，校医院与家属活动点是重点 |
| 户外劳动者 | 1.5 | 保洁、绿化、门岗、后勤连续户外作业 |
| 骑手 | 1.4 | 集散点等单、暴晒，缺少遮阴与饮水 |

**高暴露**的定义：`heat ≥ 72` 且该人处于户外。

## 六、指标

| 指标 | 定义 |
| --- | --- |
| 加权平均热指数 | `Σ(heat × 户外人数) / Σ户外人数` |
| 户外高暴露人数 | 所有 `heat ≥ 72` 地块上的户外人数之和 |
| 脆弱群体高暴露人数 | 上者中属于儿童 / 老人 / 户外劳动者 / 骑手的部分 |
| 脆弱群体高暴露率 | `脆弱群体高暴露人数 / 脆弱群体户外人数` |
| 学生高暴露率 | `学生高暴露人数 / 学生户外人数` |
| **公平差** | `脆弱群体高暴露率 − 学生高暴露率`（百分点 pp） |
| 遮阴覆盖 | 遮阴贡献 ≥ 3 的地块上的户外人口占比 |
| 舒适度指数 | 按户外人数加权的舒适度贡献，放大 7 倍后截断到 0–100 |
| 公众支持度 | `60 + Σ设施支持度 + 事件修正`，截断到 0–100 |

## 八、五个关卡

| 关 | 名称 | 时刻 | 天气 | 预算 | 解锁 |
| --- | --- | --- | --- | --- | --- |
| 1 | 正午的中心广场 | 12 / 14 | 常规 | 20 | 行道树、遮阳棚 |
| 2 | 热浪橙色预警 | 12 / 14 / 18 | 橙色 | 30 | + 浅色反光铺装、透水铺装 |
| 3 | 傍晚的运动场 | 14 / 18 | 黄色 | 28 | + 雾森降温、浅水景观 |
| 4 | 一个都不能少 | 08 / 12 / 14 / 18 | 橙色 | 62 | + 饮水补给点、绿色屋顶 |
| 5 | 清凉校园 · 沙盒 | 08 / 12 / 14 / 18 | 常规 | 不限 | 全部 |

每关只有 **2 个**验收目标（1 个核心 60 分 + 1 个进阶 40 分），降低理解成本。

### 各关验收目标

**第 1 关**（14:00 验收）
- 核心｜高暴露人数 ≤ 200（60 分）
- 进阶｜舒适度指数 ≥ 30（40 分）

**第 2 关**（14:00 验收）
- 核心｜高暴露人数 ≤ 300（60 分）
- 进阶｜遮阴覆盖户外人口比例 ≥ 50%（40 分）

**第 3 关**（18:00 验收）
- 核心｜高暴露人数 ≤ 60（60 分）
- 进阶｜舒适度指数 ≥ 35（40 分）

**第 4 关**（14:00 验收）
- 核心｜公平差 ≤ 10 pp（60 分）
- 进阶｜高暴露总人数 ≤ 1500（40 分）

> 这一关的核心目标在**开局是不达标的**：脆弱群体与学生的暴露差约 11.5 pp。
> 必须把预算真正投向后勤休息点、外卖集散点、校医院、幼儿园这些"人不多但最脆弱"的点位，
> 才能把它压到 10 pp 以内。只跟着参谋建议走（按"改善效果 ÷ 造价"排序）会因为
> 那些点位人数少、得分低而漏掉它们，公平差几乎纹丝不动——
> `balance.test.ts` 里有一条回归断言专门守住这个设计意图。

**第 5 关**：沙盒，不设验收线。

### 星级

```
得分率 = 达成目标分数 / 目标总分
≥ 85% → ★★★     ≥ 60% → ★★     ≥ 30% → ★     否则 → 未达标
```

## 十、参谋建议（本地规则推理）

`advise(state, hour)` 的实现：

1. 计算候选地块得分：`户外人数 × 脆弱群体加成 × max(0, heat − 55)`，
   即“又热、又有人、脆弱群体占比高”的地块优先；
2. 对当前解锁的每种工具，在每个可放置的候选地块上**模拟放置一次**，
   用综合改善分排序：

```
改善分 = (高暴露人数下降) × 0.6
       + (脆弱群体高暴露下降) × 1.2
       + (公平差下降) × 4
       + (加权平均热指数下降) × 12
       + (舒适度提升) × 0.8
```

3. 每种工具保留最优点位，取总分最高的三条返回，并附上可解释的理由。

> 该建议**不调用任何大模型 API**，现场断网可运行，答辩时可逐条解释。

## 十一、平衡验证

`src/lib/balance.test.ts` 用两种机器人玩家跑完全部关卡，作为回归测试：

- **目标感知贪心**（代表看懂目标、认真规划的玩家）：每个非沙盒关卡都必须拿到 **3 星**；
- **参谋贪心**（代表只跟着建议走的玩家）：**拿不到满分**，第四关甚至只有 1 星；
- **原地不动**（什么都不做）：必须**无法达标**。

这保证关卡既**可达**，又**保留了真实的决策空间**。
